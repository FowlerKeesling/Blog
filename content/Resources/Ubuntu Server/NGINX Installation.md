> [!info] Nginx Proxy Manager (npm)\
> This application secures remote connections and provides certifications (https). Without this, the server's applications would not work on iphone or other devices that require https certificates.

1. Create the docker compose file.

```Bash
cd npm
mkdir data
nano docker-compose.yml
```

> [!todo]- Command Breakdown\
> **Why:** These commands create the folder structure needed for the Nginx Proxy Manager Docker container. The `data` folder will store persistent application data, and the `docker-compose.yml` file will define how Docker should create and run the container.
>
> **cd:** Stands for "change directory." This command is used to navigate between folders in the terminal.
>
> **npm:** The name of the directory you are moving into. In this setup, this folder will contain the files related to Nginx Proxy Manager.
>
> **mkdir:** Stands for "make directory." This command creates a new folder.
>
> **data:** The name of the directory being created. This folder will store persistent data generated by the Docker container, such as configuration files and application settings.
>
> **nano:** A simple terminal-based text editor used to create and modify text files directly from the command line.
>
> **docker-compose.yml:** The name of the Docker Compose configuration file being created. This file defines how Docker should build, configure, and run one or more containers.

2. Nano will open an empty file in the main window of VS Code. Paste following the configuration into the this file then save using CTRL or ⌘ + S.

```YAML
services:
  nginx_proxy_manager:
    image: "jc21/nginx-proxy-manager:latest"
    container_name: nginx_proxy_manager
    restart: unless-stopped
    network_mode: "host"
    ports:
      - "80:80"    # HTTP
      - "443:443"  # HTTPS
      - "81:81"    # Admin Panel
    volumes:
      - ./data/npm_data:/data
      - ./data/npm_letsencrypt:/etc/letsencrypt
      - ./data/npm_logs:/var/log/nginx  
    environment:
      DB_SQLITE_FILE: "/data/database.sqlite" # Using SQLite instead of MySQL for simplicity
      INITIAL_ADMIN_EMAIL: admin@example.com #Change me
      INITIAL_ADMIN_PASSWORD: changeme #Change me
```

3. Start the docker container.

```bash
sudo docker compose up -d  
```

> [!todo]- Command Breakdown\
> **Why:** This command starts the Docker containers defined in the `docker-compose.yml` file. The `-d` option runs the containers in the background, allowing them to continue running after you close the terminal.
>
> **sudo:** Runs the command with administrative (superuser) privileges. This is required because the current user may not yet have permission to communicate with the Docker service.
>
> **docker:** The Docker command-line interface (CLI). It allows you to interact with the Docker Engine from the terminal.
>
> **compose:** A Docker feature that allows you to define and manage multiple containers using a configuration file, usually named `docker-compose.yml` or `compose.yaml`.
>
> **up:** Creates and starts the containers defined in the Docker Compose file. If the required images are not already available, Docker will download them automatically.
>
> **-d:** Stands for "detached mode." It runs the containers in the background instead of keeping the terminal attached to the container logs.

4. Verify the container is running. If the application is running, it should appear in the list.

```bash
sudo docker ps
```

> [!todo]- Command Breakdown\
> **Why:** This command displays the Docker containers that are currently running. It is useful for verifying that a container started successfully and checking basic information such as its name, status, and network ports.
>
> **sudo:** Runs the command with administrative (superuser) privileges. This is required because the current user may not yet have permission to communicate with the Docker service.
>
> **docker:** The Docker command-line interface (CLI). It allows you to interact with the Docker Engine from the terminal.
>
> **ps:** Stands for "process status." In Docker, this command lists currently running containers and displays information about their state.
