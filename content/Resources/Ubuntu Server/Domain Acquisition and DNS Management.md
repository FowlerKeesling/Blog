> [!Info] Domain Names
> A domain name is a readable title that routes to a server's IP address. For instance, https://notes.fowlercloud.org routes to my notes server IP.

1. Purchase a domain name from [Porkbun](https://porkbun.com/products/domains)
2. Open [Cloudflare](https://www.cloudflare.com/) and create a free account
3. Follow [this guide](https://www.youtube.com/watch?v=OuQbsdwFTA0) to use Cloudflare as a DNS manager for the server's domain name
